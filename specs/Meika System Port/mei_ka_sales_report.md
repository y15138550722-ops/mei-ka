# 数据中心 · 销售报表

依据用户提供的《BRD26005 数据中心业务需求文档》v1.1（2026-09-27）实现。入口：管理端 → 数据中心 → 销售报表，路由 `/data-center/sales-report`。

## 页面与交互

- 时间支持日、周、月、季度、年聚合；周一为一周起点。当前统计范围沿用近30天。按用户最新截图删除快捷时间（今日、本月、近30天、全部时间）、日期/渠道/产品筛选表单及查询/重置按钮；日/周/月/季度/年聚合切换集中放在趋势区，切换不改变统计日期范围。
- 渠道按用户最新要求汇总为自营、合作渠道、租车公司、代理商四类。自营包括配置中的淘宝店、微信/支付宝小程序及自营未细分来源；合作渠道包括Klook、携程、哈啰、飞猪历史来源；租车公司包括avis、sixt、悟空租车、enterprise、europcar及一嗨；代理商取完整代理商名。按渠道主表显示四类合计，展开分类查看具体店铺/渠道，再展开具体渠道查看产品销量、销售额和客单价。未知历史来源保留为未细分项，不虚构渠道归属。
- 产品按产品线与具体产品归类。完整配置翻译认证（小白本、NAATI澳大利亚、NZTA新西兰、西班牙/德/法/意宣誓翻译电子版及原件、ATIO、波兰语宣誓）、公证（公证单号/双号、海牙单号/双号）、IDD/IDP（IDP、IDP加急、IDD国际驾照、IDD加急）。底层统计保留完整产品配置，产品视图展示当前统计范围内的销售结果。产品名优先 `products[0].name`，其次 `title`，本地订单兼容 `productName`；统一常见空格、括号及名称别名，电子版与原件分开统计，未识别产品保留原名。
- 页面按“销售概览 → 销售分析 → 销售趋势”顺序组织。主概览用三张卡片突出销售额、订单量与客单价；退单量和退单金额置于下方辅助信息条。五个指标均展示环比与同比。环比为紧邻的等长区间；同比为去年同日期范围，闰日按月末对齐。对比日期显式展示，零基期不生成增长率。
- 趋势图支持销售额/订单量切换，缺少订单的周期补零。通过一个对比选择器切换不对比、环比、同比、自定义日期区间；本期与对比曲线按第N个统计周期对齐，悬停展示各自实际日期。两个区间长度不同仍展示各自全部周期，不补造无对应周期的数据。对比共用当前渠道/产品条件，切换日/周/月/季度/年同时更新两条曲线；自定义模式的指标卡额外显示自定义变动率。分析区的汇总表与分布图共用当前统计范围，切换按渠道/按产品时同步更新。
- 销售分析按用户反馈精简为“按渠道 / 按产品”两个视图，共用当前统计日期范围。默认按渠道，先列自营、合作渠道、租车公司、代理商四类汇总；展开后列具体店铺/渠道，渠道行可继续展开产品明细。按产品时直接列产品并标注产品线。
- 汇总表仅展示订单量、销售额和客单价；退单指标在概览辅助信息条及导出中展示。渠道行点击“查看产品”原地展开产品销量、金额和客单价及合计，再次点击可收起。详情不改变全局筛选，也不跳转视图。按产品表直接展示产品数据。金额从高到低排列，每页10项，超过一页才显示上一页/下一页。
- 销售分析在宽屏采用“左侧汇总表 + 右侧对应分布图”，窄屏分布排在表格下方。按渠道时分布图按四类渠道汇总；按产品时按产品汇总。仅显示当前维度的一张分布图，按全量汇总销售额计算占比、展示前5项；分布与分页无关。图表、汇总、趋势、详情和导出均使用同一统计范围。导出入口保留在页面顶部，包含全量结果，不受分页及明细展开状态限制。

## 指标口径

- 有效订单：排除 `status=1` 待付款。取消和退单仍包含在订单量与销售额中，退单指标单列，不直接计算销售净额。
- 销售额：有效订单 `totalprice` 合计。数值字符串转数值，按分累计，避免浮点累加误差。
- 退单：`refund_time` 非空或 `status=-1`。本地 `cancelled` 映射取消；`rejected` 不自动视为退款。
- **2026-11-03 用户确认：退单量及退单金额按下单日期归属，沿用当前方案。**
- 客单价：销售额 / 有效订单量。无订单时显示“—”。缺失或无效金额不估算；金额展示已知合计并提示缺失，客单价和相关金额增长率暂停计算。
- 渠道依 `agent_nick_name`、`nick_name`、`sourcefrom` 及现有明确来源字段映射。按用户截图展示完整代理商名并按完整名称分组，避免同名前缀合并。
- 明确关联的API订单与管理端副本只计一次，管理端保存销售事实，API保留渠道归因；不同接口同号订单独立计数。

## 数据边界

当前前端读取主订单、Klook和哈啰本地演示订单；未连接BRD中的线上销售API。若演示订单缺少 `totalprice`，读取其历史锁价。未记录的店铺、代理商名及退款时间不补造。现有全局登录保护继续生效；角色权限、T+1作业与线上对账需要后端接入。本页不执行录入、审核、发货等业务操作。

日期缺失的订单不进入日期报表，在数据说明中记录其数量。CSV采用UTF-8 BOM并转义单元格公式前缀，导出金额与页面同源。导出包括全量汇总、时间趋势、渠道分布、产品分布、所选对比期的趋势/指标/变动率，以及渠道×产品明细；各节明确为同一批订单的不同视图，避免重复累计。导出使用当前统计日期范围，不使用尚未提交的对比草稿。

## 验证

`node --test tests/salesReport.test.ts` 覆盖金额、退单、渠道、去重、日期、比较区间、交叉筛选与导出；`npm run build` 验证类型与生产构建。

## 2026-11-03 联动分析验收

渠道层级、具体渠道、产品明细和时间趋势的数量/金额须逐级相等。底层统计仍验证时间、渠道和产品组合条件的汇总一致性；当前页面已按用户要求移除筛选入口。配置中的五家淘宝店、三个合作渠道、五家租车公司继续用于归因；不编造零销量渠道的订单。未知店铺不分摊到五家已知店铺。导出以当前已应用查询为准，包含完整汇总和交叉明细，分节标记避免重复累计。
