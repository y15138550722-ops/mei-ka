# 生产端报表：小白本数据统计

更新日期：2026-11-02

完整需求方案见：[小白本数据统计方案](../小白本/小白本数据统计方案.md)。本文保留简要实现说明。

## 页面与查询

在“生产端 → 报表”增加“小白本数据统计”页签。默认查询北京时间当天，支持开始日期、结束日期及订单来源筛选，点击“搜索”应用条件；“重置”恢复当天与全部来源。结束日期早于开始日期时提示错误，并保留原结果。

页面仅提供“来源汇总”。汇总固定展示六类来源，即使数量为零也保留；四个合计指标、表格和详细来源使用同一统计结果。

列表和来源筛选项统一按以下顺序展示：自营订单（含自营小程序）、渠道订单、合作租车公司、携程订单、哈啰订单、klook订单。

“自营订单（含自营小程序）”、“渠道订单”和“合作租车公司”的列表名称旁提供“查看详细来源”按钮，点击后在对应行下方展开该类别的细分统计，再次点击“收起来源”关闭；一次展开一行。详细来源按当前查询区间统计，以纯表格展示订单、翻译、制作和发货数量，以及与父行一致的小计。搜索或重置时收起明细。自营明细包括淘系、微信小程序、支付宝小程序；渠道明细包括山东译沃教育科技有限公司、常州语联、深空粒子科技、杭州越珵科技有限公司、武汉鸿鹄之志翻译服务有限公司、易办通网络科技（洛阳）有限公司、万腾翻译、KARLOWEN旗舰店、杭州云典及其他渠道商。无法识别到上述合作方的存量渠道来源计入“其他渠道商”。携程、哈啰和 klook 行不提供此按钮。

## 来源方案

| 展示名称 | 来源规则 |
| --- | --- |
| 自营订单（含自营小程序） | 自营淘系、自营微信小程序、自营支付宝小程序 |
| 渠道订单 | 九个明确合作方及其他渠道商；无法识别到合作方的存量渠道来源计入其他渠道商 |
| 携程订单 | 携程 API 及历史携程来源 |
| 哈啰订单 | 哈啰接口来源 |
| klook订单 | Klook 接口来源 |

主订单新增可选 `sourceChannel`，记录原始获客来源，优先于旧的粗分类 `channel`：

| `sourceChannel` | 统计归类 |
| --- | --- |
| `self_taobao` / `self_wechat` / `self_alipay` | `self` |
| `ctrip_api` | `ctrip` |
| `klook_api` | `klook` |
| `hello_api` | `hello` |
| 九个 `partner_*` 来源标识及 `shenkong_channel` | 对应渠道合作方明细 |
| 其他未映射的历史渠道来源 | 渠道订单 / 其他渠道商 |

历史数据未记录细分来源时：`channel=ctrip` 归携程；`agentLevel=self` 且 `channel=fliggy/private` 归自营；其余归渠道。此规则是现有数据下的兼容方案，不凭渠道名推测具体小程序。新增接单入口应保存 `sourceChannel`，本次报表不改写历史订单。

## 计数口径

统计对象为产品名称包含“小白本”的订单，排除 IDP、宣誓翻译、公证等其他产品。数据直接来自主订单、Klook、哈啰订单服务，不额外拼接报表示例数据。当前项目服务基于本地演示数据与浏览器存储，尚未连接生产统计接口。

| 指标 | 日期依据 | 去重规则 |
| --- | --- | --- |
| 订单数量 | `createdAt` | 一个业务订单一次 |
| 翻译数量 | 首次有效“已翻译”日志 | 一个业务订单一次 |
| 制作数量 | 首次有效“已制作”日志 | 一个业务订单一次 |
| 发货数量 | `shippedAt`、有效“已发货”日志中的最早时间 | 一个业务订单一次 |

- 外部订单的 `orderRecordLabel/orderRecordAt` 可补充该字段明确描述的环节，不能推算其他阶段；缺少时间或日期无效时，该环节不计数。
- 同一来源按订单号去重。外部订单通过 `managementOrderId` 关联主订单时合并事件、使用接口渠道，避免同一业务订单统计两次；无关联且不同来源的同号订单各自计数。
- 先确定首次事件、再筛选日期，避免再次导出或重复操作落在后续日期而重复计数。
- 无时区时间按北京时间解释，带时区时间转换为北京时间，日期范围包含两端。
- 四项数量均按各自发生日统计，不按创建日筛选后再计算完成数量。因此当天完成数量可能超过当天新增订单数量。
- 取消或拒绝订单保留已发生的创建与完成记录，不因当前状态改变而删减历史工作量。
- 计数单位为订单“单”，不按文件、打印张数或重复操作次数统计。
- 订单变更、接口订单变更、其他标签页存储变更及窗口重新聚焦时刷新当前查询；无记录时显示零值与空态。

## 验证
