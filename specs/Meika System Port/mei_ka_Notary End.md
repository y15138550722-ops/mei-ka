## 1. 背景与目标

### 1.1 背景

公证处工作台是订单中心之外的履约工作区，面向公证专员。该模块承接公证订单在公证处侧的处理链路，用于完成以下核心动作：

- 接收来自公证订单管理页审核通过后推送的订单
- 在公证处侧查看待审核、制作中、已完成、已驳回等状态
- 对待审核订单进入预览审核页执行通过/驳回
- 对制作中订单执行单条或批量完成

当前实现中，公证订单管理页与公证订单页已解耦：

- 管理页审核通过后，管理页订单进入 `pending_production`
- 管理页待制作订单点击“送审”并选择公证处后，公证处订单页接收同订单并保存为 `pending_review`
- 公证处审核通过后，公证处订单进入 `in_production`，并同步管理页订单进入 `in_production`
- 管理页待制作口径仍聚合展示 `pending_production` 与 `in_production`，但公证处已审核通过后不再显示“送审”按钮
- 公证处制作完成后，公证处订单进入 `completed`，管理页订单回到可物流发货状态；管理页填写物流后同步主订单与公证处订单物流字段
- 公证订单页使用独立持久化数据源，承接公证处后续处理链路，并与管理页主订单做关键状态同步

### 1.2 目标

| # | 目标           | 描述                                                             |
| - | -------------- | ---------------------------------------------------------------- |
| 1 | 提升履约效率   | 支持单条下载模板、单条/批量标记完成                              |
| 2 | 固化状态推进   | 明确公证处侧各状态的显示口径、动作入口和流转结果                 |
| 3 | 保持审核一致   | 预览审核页提供统一的文件预览、审核摘要、通过/驳回动作            |
| 4 | 降低操作风险   | 对批量动作、驳回原因、空数据、文件加载异常提供明确约束和反馈     |
| 5 | 明确实现边界   | 区分当前已实现能力与当前页面尚未提供的入口，避免 PRD 超前描述    |
| 6 | 保持上下游同步 | 固化公证处审核、完成、管理页物流发货与查看订单物流信息的同步口径 |

### 1.3 非目标

- 不实现真实公证文书在线编辑
- 不实现真实外部电子签、法务系统或政府系统对接
- 不实现真实打印、第三方物流履约和签收回传
- 不实现公证处侧角色细分 RBAC
- 不实现公证处侧物流录入；当前物流发货入口位于公证订单管理页

## 2. 范围（Scope）

### 2.1 In Scope

- 公证处订单列表页
- 公证处预览审核页
- 状态标签：全部 / 待审核 / 制作中 / 已完成 / 已驳回
- 制作中单条下载模板
- 制作中单条完成
- 制作中批量完成
- PDF / 图片 / DOCX 文件预览
- 驳回原因填写与驳回同步
- 公证处审核通过同步管理页制作中状态
- 公证处制作完成同步管理页物流发货入口
- 管理页物流发货后同步物流字段至公证处订单，并在查看订单物流信息中回显
- 公证处数据源初始化、持久化与去重逻辑

### 2.2 Out of Scope

- 管理页“选择推送公证处”弹窗本身
- 公证订单管理页的列表检索、导出、已取消逻辑
- 公证处侧物流录入
- 真实物流履约、签收回传与物流轨迹查询

### 2.3 路由与入口

| 页面                         | 路由                               | 说明                       |
| ---------------------------- | ---------------------------------- | -------------------------- |
| 公证处订单列表页             | `/notary/orders`                 | 工作台主入口               |
| 公证处订单列表页（指定状态） | `/notary/orders?status=<status>` | 通过 query 初始化状态标签  |
| 公证处预览审核页             | `/notary/orders/:id/preview`     | 仅待审核订单可执行审核动作 |

当前 query 支持的状态口径：

- `pending_review`
- `in_production`
- `completed`
- `rejected`
- 兼容历史 query：若传入 `translating` 或 `pending_production`，会在页面初始化时映射为 `in_production`
- 若传入 `shipped`，会在页面初始化时映射为 `completed`

## 4. 页面结构与信息架构

### 4.1 列表页结构

公证处订单列表页由以下区域组成：

1. 顶部导航区
   - 面包屑：`后台管理 / 公证订单`
   - 页面标题：`公证订单`
2. 筛选区
   - 第一行：产品筛选、语言筛选、优先级筛选
   - 语言筛选：需先选择产品后启用，选项与用户端“选择驾照翻译认证产品 / 语言选择”联动规则一致
   - 优先级筛选：紧急办理 / 优先办理 / 正常办理
   - 第二行：关键字搜索，支持姓名、身份证号 / 证件号、手机号、驾照号，输入框文案为 `请输入姓名、身份证号、手机号`
   - 搜索 / 重置按钮：放置在筛选区域右侧；筛选条件变更后不立即过滤，点击搜索后生效
   - 已启用筛选项数量、结果总数
3. 状态标签区
   - 全部、待审核、制作中、已完成、已驳回
   - 每个标签显示对应状态数量
4. 批量操作区
   - 当状态为制作中时显示“已选择 X 条制作中订单 + 批量完成”
5. 列表表格区
   - 序号
   - 产品
   - 证件信息
   - 收货信息
   - 优先级
   - 驳回原因（仅已驳回状态显示）
   - 状态
   - 操作
   - 复选框列（仅制作中显示）
6. 分页区
   - 默认每页 20
   - 支持切换分页大小

### 4.2 预览审核页结构

公证处预览审核页由以下区域组成：

1. 顶部工具栏
   - 返回列表按钮

   - 当前订单号

## 5. 数据来源与持久化

### 5.1 数据源定义

公证处工作台使用独立数据源 `meika-notary-office-orders`，不直接复用公证订单管理页列表状态。

| 数据项         | 存储位置                                            | 说明                                            |
| -------------- | --------------------------------------------------- | ----------------------------------------------- |
| 公证处订单列表 | `localStorage.meika-notary-office-orders`         | 公证处侧订单数据源                              |
| 公证处数据版本 | `localStorage.meika-notary-office-orders-version` | 当前版本号 `v4-notary-review-production-flow` |
| 主订单数据     | `mockDataService / meika-orders`                  | 管理页、公证订单管理页使用的主订单数据          |

### 5.2 默认初始化口径

公证处数据初始化由两部分组成：

1. 来自管理页已推送公证处的公证订单
   - 条件：`productCategory = notary` 且存在 `pushedNotaryOfficeId` / `pushedNotaryOfficeName` / 日志包含“推送至”
   - 若管理页订单状态为 `pending_production`，初始化到公证处侧时会被归一为 `pending_review`
2. 公证处独立待审核种子数据
   - 当前内置 10 条 `pending_review` mock 订单
   - 每条包含默认公证处信息：北部湾公证处或张江公证处

### 5.3 去重与清洗规则

- 以 `orderId` 为唯一键去重
- 明确移除的订单号：`MK2600057`、`MK2600061`
- 若历史缓存中存在“来自管理页推送”的订单且状态仍为 `translating`，加载时会自动规范为 `pending_review`
- 若历史缓存中存在 `pending_production` 公证处订单，加载时会自动规范为 `in_production`

## 6. 状态模型与口径定义

### 6.1 源状态与展示状态

当前公证处工作台接收的源状态集合为：

- `pending_review`
- `in_production`
- `shipped`
- `completed`
- `rejected`

当前公证处工作台的可见状态标签集合为：

- `pending_review`
- `in_production`
- `completed`
- `rejected`

其中：

- `shipped` 在界面层统一映射为 `completed`
- 历史状态 `translating` 与 `pending_production` 在 query / 兼容逻辑中映射为 `in_production`
- `cancelled` 不在公证处工作台展示

### 6.2 状态定义表

| 状态               | 展示文案 | 来源                       | 当前页可执行动作               | 说明                                   |
| ------------------ | -------- | -------------------------- | ------------------------------ | -------------------------------------- |
| `pending_review` | 待审核   | 种子订单或管理页送审后进入 | 预览审核                       | 可进入预览审核页执行通过/驳回          |
| `in_production`  | 制作中   | 公证处审核通过后进入       | 制作并下载、单条完成、批量完成 | 完成后进入已完成；模板下载不会改变状态 |
| `shipped`        | 已完成   | 历史兼容状态               | 无                             | 在页面上折叠显示为已完成               |
| `completed`      | 已完成   | 制作完成                   | 无                             | 列表仅展示，无动作按钮                 |
| `rejected`       | 已驳回   | 公证处审核驳回             | 无                             | 列表展示驳回原因                       |

### 6.3 状态推进规则

| 当前状态           | 触发动作                 | 下一个状态                                           | 发生位置         |
| ------------------ | ------------------------ | ---------------------------------------------------- | ---------------- |
| 管理页待审核       | 管理页审核通过           | 管理页：`pending_production`                       | 管理页           |
| 管理页待制作       | 点击“送审”并选择公证处 | 公证处：`pending_review`；管理页保留待制作聚合口径 | 管理页与数据同步 |
| `pending_review` | 预览页审核通过           | 公证处：`in_production`；管理页：`in_production` | 公证处预览页     |
| `pending_review` | 预览页审核驳回           | 公证处：`rejected`；管理页：`pending_production`，显示“送审”按钮 | 公证处预览页     |
| `in_production`  | 下载模板                 | `in_production`                                    | 公证处列表页     |
| `in_production`  | 单条标记完成             | `completed`                                        | 公证处列表页     |
| `in_production`  | 批量标记完成             | `completed`                                        | 公证处列表页     |
| `completed`      | 同步管理页               | 管理页：`pending_production`，显示物流发货入口     | 公证处完成同步   |
| 管理页待发货       | 填写物流并确认发货       | 管理页：`shipped`；公证处：`shipped`             | 管理页与数据同步 |

### 6.4 状态机

```mermaid
flowchart TD
    A["管理页待审核"] -->|"审核通过"| B["管理页待制作"]
    B -->|"送审并选择公证处"| C["公证处待审核"]
    C -->|"审核通过"| D["公证处制作中"]
    C -->|"审核驳回"| H["公证处已驳回 / 管理页待制作，可再次送审"]
    D -->|"制作完成"| E["公证处已完成 / 管理页待物流发货"]
    E -->|"管理页物流发货"| F["两侧已发货"]
```

### 6.5 当前实现边界说明

- `translating` 为历史兼容状态，当前送审入场状态为 `pending_review`
- 预览审核页只有当订单状态为 `pending_review` 时才允许执行通过/驳回
- `completed` 和 `rejected` 状态在公证处列表中仅展示，不提供继续操作；被驳回订单在管理页回到待制作后允许再次送审
- 公证处工作台不提供物流录入口；物流发货在管理页完成，并同步物流字段到主订单与公证处订单

## 7. 核心业务规则

| 编号      | 规则                                                                                                                       |
| --------- | -------------------------------------------------------------------------------------------------------------------------- |
| BR-NW-001 | 工作台仅展示 `productCategory = notary` 且状态属于公证处源状态集合的订单                                                 |
| BR-NW-002 | 列表筛选条件之间为 AND 关系                                                                                                |
| BR-NW-003 | 产品筛选当前固定支持：`公证单号 / 公证双号 / 公证海牙单号 / 公证海牙双号`                                                |
| BR-NW-004 | 关键字搜索匹配 `licenseName / customerName / customerPassport / customerPhone / licenseNo` 的小写拼接字符串，大小写不敏感 |
| BR-NW-005 | 状态 query 参数会同步驱动当前状态标签；传入 `shipped` 会映射为 `completed`                                             |
| BR-NW-006 | 语言筛选不可独立使用；未选择产品时语言筛选禁用，选择产品后按产品联动展示可选语言                                        |
| BR-NW-007 | 语言联动规则与用户端一致：`公证双号 / 公证海牙双号` 支持英语、意大利语；其他公证产品支持英语、法语、西班牙语、意大利语、德语 |
| BR-NW-008 | 列表筛选条件不随输入或下拉变更实时生效，必须点击“搜索”后才应用；“重置”同时清空待输入条件与已应用条件                    |
| BR-NW-009 | 列表排序先按优先级升序：紧急办理、优先办理、正常办理；同优先级内再按推送至公证处时间正序，先推送的订单在前              |
| BR-NW-010 | 推送至公证处时间优先取送审 / 公证处接收 / 推送日志时间，缺失时回退 `createdAt`，再回退 `updatedAt`                       |

## 8. 功能需求

### 8.1 列表页筛选

#### 8.1.1 筛选字段定义

| 字段            | 类型        | 必填 | 默认值  | 取值来源         | 说明                                                       |
| --------------- | ----------- | ---- | ------- | ---------------- | ---------------------------------------------------------- |
| `productName` | Enum/String | 否   | 空      | 用户选择         | 按产品名称精确筛选                                         |
| `language`    | Enum/String | 否   | 空      | 产品联动         | 需先选择产品后启用；按订单语言精确筛选                     |
| `priority`    | Enum        | 否   | 空      | 用户选择         | 按办理优先级筛选：紧急办理、优先办理、正常办理             |
| `keyword`     | String      | 否   | 空      | 用户输入         | 输入框文案：`请输入姓名、身份证号、手机号`                 |
| `statusTab`   | Enum        | 否   | `all` | query / 页面点击 | 按状态标签筛选；状态标签点击后立即生效                     |

#### 8.1.2 筛选逻辑

- 产品：订单 `productName === appliedFilterProduct`
- 语言：不可独立使用；仅当产品筛选已应用且语言已应用时，判断 `order.language === appliedFilterLanguage`
- 语言选项联动：
  - `公证双号`、`公证海牙双号`：`英语 / 意大利语`
  - `公证单号`、`公证海牙单号`：`英语 / 法语 / 西班牙语 / 意大利语 / 德语`
  - 未选择产品时语言下拉禁用，提示“请先选择产品”
- 优先级：按 `processType` 归一为 `urgent / priority / normal` 后匹配
- 关键字：搜索 `licenseName / customerName / customerPassport / customerPhone / licenseNo`
- 状态：用展示状态口径判断，即 `shipped` 视作 `completed`
- 筛选条件之间为 AND 关系

#### 8.1.3 筛选触发

- 产品、语言、优先级、关键字输入值变更时，仅更新待搜索条件，不直接刷新列表
- 点击“搜索”后，将待搜索条件写入已应用筛选条件，并重置当前页为第 1 页
- 状态标签不受搜索按钮控制，点击状态标签后立即生效

#### 8.1.4 重置逻辑

- 清空产品筛选
- 清空语言筛选
- 清空优先级筛选
- 清空关键字筛选
- 同时清空待搜索条件与已应用筛选条件
- 当前页重置为第 1 页
- 不主动清空状态标签

### 8.2 状态标签与统计

#### 8.2.1 标签集合

- 全部
- 待审核
- 制作中
- 已完成
- 已驳回

#### 8.2.2 数量统计规则

- `全部` = 所有公证处源状态订单数量
- 其他标签 = 使用展示状态口径过滤后的数量
- `completed` 统计同时包含 `shipped` 和 `completed`

### 8.3 列表字段定义

| 字段名   | 类型        | 来源                             | 展示说明                                     | 示例                  |
| -------- | ----------- | -------------------------------- | -------------------------------------------- | --------------------- |
| 序号     | Number      | 分页序号计算                     | `(currentPage - 1) * pageSize + index + 1` | `21`                |
| 产品     | String      | `order.productName`            | 主文案展示                                   | `公证单号`          |
| 语言按钮 | String      | `order.language`               | 只读胶囊展示                                 | `英语`              |
| 姓名     | String      | `order.licenseName / order.customerName` | 证件信息区展示                         | `林知夏`            |
| 驾照号   | String      | `order.licenseNo`              | 证件信息区展示                               | `D30000001`         |
| 准驾车型 | String      | `order.licenseCategory`        | 证件信息区展示                               | `C1`                |
| 收货人   | String      | `order.customerName`           | 收货信息区展示                               | `林知夏`            |
| 手机号   | String      | `order.customerPhone`          | 收货信息区展示                               | `13800192011`       |
| 收货地址 | String      | `order.deliveryAddress`        | 收货信息区展示                               | `上海市浦东新区...` |
| 优先级   | Enum        | `order.processType`            | 标签展示：紧急办理、优先办理、正常办理       | `紧急办理`          |
| 驳回原因 | String      | `rejectReason / remark / 日志` | 仅已驳回列表显示                             | `扫描件不清晰`      |
| 状态     | Enum        | 状态映射                         | 标签展示                                     | `制作中`            |
| 操作     | ActionGroup | 状态驱动                         | 预览 / 制作并下载 / 制作完成                 | `预览`              |

#### 8.3.1 列布局规则

- 优先级列固定展示在收货信息之后、驳回原因 / 状态之前
- 收货信息与优先级列之间保持紧凑间距，避免因收货地址列过宽导致视觉断层
- 产品、证件信息、收货信息等信息密集列使用固定或上限宽度，长文本按省略或换行策略处理，不挤压优先级、状态、操作列

### 8.4 列表排序与分页

#### 8.4.1 排序规则

- 默认先按优先级排序：
  1. 紧急办理
  2. 优先办理
  3. 正常办理
- 同优先级内按推送至公证处时间正序排序，先推送的订单在前
- 推送至公证处时间取值：
  - 优先取日志中匹配“送审至 / 公证处已接收 / 推送至”的时间
  - 若无，回退 `createdAt`
  - 若仍无，回退 `updatedAt`
- 若优先级与推送时间均相同，则按 `orderId ASC`

#### 8.4.2 分页规则

- 默认每页：20
- 当前页码变化只影响前端切片，不请求远程数据

### 8.5 制作中文件下载

#### 8.5.1 单条下载模板

入口：

- 列表页中 `in_production` 行的“制作并下载”按钮

处理：

1. 获取订单
2. 依次尝试两个 ZIP 模板路径
3. 生成下载链接并触发浏览器下载
4. 订单保持 `in_production`
5. 写入“下载模板并进入制作中”日志

失败提示：

- `压缩包模板下载失败，请稍后重试`

#### 8.5.2 批量下载模板（历史能力说明）

当前页面批量操作区仅保留“批量制作完成”。批量下载方法仍作为内部能力存在，但当前 UI 不展示批量下载入口。

历史入口：

- 状态标签为制作中时的顶部批量操作区

处理：

1. 校验当前选中订单不为空
2. 下载同一个模板 Blob
3. 为每个选中订单触发下载
4. 选中订单保持 `in_production`
5. 写入“批量下载模板并进入制作中”日志
6. 清空选中状态

失败提示：

- 未选中：`请先选择制作中的订单`
- 模板失败：`压缩包模板下载失败，请稍后重试`

### 8.6 制作中动作

#### 8.6.1 单条标记完成

入口：

- 列表页中 `in_production` 行的“已完成”按钮

处理：

1. 获取订单
2. 更新状态为 `completed`
3. 写入“制作完成”日志
4. 同步管理页同订单状态为 `pending_production`，并记录“制作完成，待物流发货”日志

#### 8.6.2 批量标记完成

入口：

- 状态标签为制作中时的顶部批量操作区

处理：

1. 校验当前选中订单不为空
2. 批量更新状态为 `completed`
3. 为每条订单补完成时间和完成日志
4. 同步管理页同订单状态为 `pending_production`，用于显示物流发货入口
5. 清空选中状态

失败提示：

- `请先选择制作中的订单`

### 8.7 预览审核页

#### 8.7.1 进入条件

- 从列表页点击待审核订单的“预览”按钮
- 当前订单必须存在
- 若订单不存在，显示 404 空态并提供返回列表按钮

#### 8.7.2 文件预览能力

当前预览支持三类文件：

| 文件类型 | 预览方式                   | 说明                                                |
| -------- | -------------------------- | --------------------------------------------------- |
| PDF      | `iframe`                 | 直接内嵌预览                                        |
| 图片     | `img`                    | 直接图片预览                                        |
| DOCX     | `iframe/srcDoc` 或回退图 | 优先解析生成 HTML；失败时回退图片；仍失败则提示下载 |

当前实现中：

- 主材料文件集使用固定演示资源
- 附件图片当前内置 8 张
- 文档下载按钮始终可用，点击后新窗口打开原始文件

#### 8.7.3 审核摘要区

侧边栏当前包含：

- 主材料数量
- 附件图片数量
- 产品/语种元信息
- 审核摘要完成度百分比
- 驾照信息摘要
- 收货信息摘要
- 历史驳回原因
- 检查清单

#### 8.7.4 审核通过

前置：

- 订单状态必须为 `pending_review`

处理：

1. 更新公证处订单状态为 `in_production`
2. 追加“审核通过，进入制作中”日志
3. 同步公证订单管理页同订单状态为 `in_production`
4. 管理页待制作聚合口径仍展示该订单，但不再显示“送审”按钮
5. 展示 toast：`审核通过，订单已进入制作中状态`
6. 延时返回制作中列表

#### 8.7.5 审核驳回

前置：

- 订单状态必须为 `pending_review`
- 驳回原因非空

处理：

1. 更新公证处订单为 `rejected`
2. 写入驳回原因、备注和驳回日志
3. 同步公证订单管理页对应订单回到 `pending_production`
4. 管理页待制作列表展示该订单，操作项显示“送审”按钮，支持再次送审
5. 管理页订单记录展示“审核驳回”和驳回时间，事件文案不带“公证处”前缀
6. 展示 toast：`订单已驳回，并返回列表`
7. 延时返回待审核列表

### 8.8 驳回弹窗

| 字段             | 类型     | 必填 | 默认值 | 说明     |
| ---------------- | -------- | ---- | ------ | -------- |
| `rejectReason` | Textarea | 是   | 空     | 驳回原因 |

交互规则：

- 原因为空时，“确认驳回”按钮禁用
- 关闭弹窗时清空已填写原因

### 8.9 管理页物流同步

#### 8.9.1 发货入口

入口：

- 公证订单管理页中，公证处已制作完成且管理页聚合状态为待制作的订单显示“物流发货”按钮
- 公证处审核通过但尚未制作完成的订单不显示“送审”按钮，也不显示“物流发货”按钮

#### 8.9.2 同步字段

管理页填写物流公司、物流单号并确认发货后，同步以下字段：

| 字段                 | 主订单 `meika-orders`     | 公证处订单 `meika-notary-office-orders` |
| -------------------- | --------------------------- | ----------------------------------------- |
| `status`           | `shipped`                 | `shipped`                               |
| `shippedAt`        | 当前时间                    | 当前时间                                  |
| `logisticsCompany` | 物流公司                    | 物流公司                                  |
| `trackingNumber`   | 物流单号                    | 物流单号                                  |
| `logs`             | 追加“物流发货：公司 单号” | 追加“物流发货：公司 单号”               |

#### 8.9.3 查看订单回显

- 公证订单管理页“查看订单”中的物流信息优先读取主订单 `logisticsCompany/trackingNumber`
- 若主订单物流字段缺失，则从公证处订单同名字段兜底展示
- 若两侧均无物流字段，则显示 `--`

## 9. 页面行为与交互细节

### 9.1 批量勾选行为

- 仅当前页、且状态命中可批量状态时，才允许勾选
- 顶部“全选”仅操作当前页可勾选订单
- 当切换状态标签导致当前状态不可批量时，选中列表自动清空
- 当订单状态变化后不再属于当前可批量状态，已选数据会在 effect 中被过滤掉

### 9.2 空态行为

- 列表无数据时展示统一空态
- 预览页订单不存在时展示 404 空态

### 9.3 Toast / Alert / 浏览器反馈

| 场景           | 反馈类型 | 文案                               |
| -------------- | -------- | ---------------------------------- |
| 审核通过       | Toast    | `审核通过，订单已进入制作中状态` |
| 审核驳回       | Toast    | `订单已驳回，并返回列表`         |
| 批量完成未选中 | Alert    | `请先选择制作中的订单`           |
| ZIP 下载失败   | Alert    | `压缩包模板下载失败，请稍后重试` |
| 管理页物流发货 | Toast    | `物流发货信息已提交`             |

## 10. 边界场景与异常处理

| 场景                                 | 当前处理方式                      |
| ------------------------------------ | --------------------------------- |
| 传入不存在的订单 ID                  | 预览页展示 404 空态并允许返回列表 |
| 列表无数据                           | 展示空态，不报错                  |
| 批量完成未勾选订单                   | 阻断并提示                        |
| 模板 ZIP 第一路径失败                | 自动尝试第二路径                  |
| 模板 ZIP 全部失败                    | 提示下载失败                      |
| DOCX 预览解析失败但存在回退图        | 展示回退图                        |
| DOCX 预览解析失败且无回退图          | 展示下载提示态                    |
| 非 `pending_review` 订单进入预览页 | 页面可查看，但通过/驳回按钮禁用   |
| 驳回原因为空                         | 确认按钮禁用                      |
| 已驳回订单被再次完成                 | 当前列表无动作入口，天然阻断      |
| 历史 `translating` 订单            | 加载时规范到 `pending_review`   |
| 公证处已审核通过后管理页重复送审     | 管理页“送审”按钮隐藏，天然阻断  |
| 管理页物流发货后查看订单物流为空     | 从公证处订单物流字段兜底展示      |

## 11. 非功能要求

- 列表筛选、排序、分页均为本地计算，交互响应应在可接受范围内
- 批量操作 100 条以内应可接受
- 文件预览失败不得导致页面崩溃
- 所有状态推进动作必须可追溯到 `logs`
- 本地缓存加载失败时应回退到默认种子数据
- 页面刷新后应保留公证处订单持久化结果

### 12.2 Gherkin 验收

**场景1: 管理页审核通过后进入公证处侧**

```gherkin
Given 管理页存在一条已审核通过的待制作公证订单
When 运营人员点击送审并选择公证处
Then 管理页订单进入待制作
And 同订单在公证处工作台进入待审核
```

**场景2: 公证处审核通过**

```gherkin
Given 公证处工作台存在一条待审核订单
When 审核人员进入预览页并点击审核通过
Then 公证处订单状态更新为制作中
And 公证订单管理页同订单同步为制作中
And 管理页不再显示送审按钮
And 页面提示审核通过
And 页面返回制作中列表
```

**场景3: 公证处审核驳回并同步管理页**

```gherkin
Given 公证处工作台存在一条待审核订单
When 审核人员填写驳回原因并确认驳回
Then 公证处订单更新为已驳回
And 公证订单管理页对应订单回到待制作列表
And 管理页订单记录展示“审核驳回”和驳回时间
And 管理页操作项显示“送审”按钮
And 两侧均记录驳回日志
```

```gherkin
Given 公证处工作台制作中列表中存在订单
```


**场景6: 管理页物流发货同步查看订单**

## 14. 当前实现备注

为避免误解，以下内容在当前版本中需特别说明：

1. `translating` 状态为历史兼容口径，当前公证处工作台默认不展示该状态，旧数据加载时会归一到 `pending_review`。
2. 预览页审核动作只对 `pending_review` 生效；其他状态即使打开预览页，也只能查看，按钮为禁用态。
3. 驳回同步到管理页时，管理页状态写入的是 `cancelled`，不是 `rejected`。
4. 公证处工作台当前不展示“推送公证处”字段，但订单数据中保留 `pushedNotaryOfficeId` 与 `pushedNotaryOfficeName`，用于初始化与同步日志。
5. 管理页物流发货字段会同步到主订单和公证处订单；查看订单物流信息优先展示主订单字段，缺失时从公证处订单兜底。
