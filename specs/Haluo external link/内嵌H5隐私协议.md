# 哈啰 App 内嵌 H5 隐私协议

版本：正式版 v1.0

更新日期：2026年5月14日

生效日期：2026年5月14日

本隐私协议适用于用户通过哈啰 App、哈啰主站或其他哈啰入口进入的国际驾照翻译认证服务 H5 页面，以及该 H5 页面提供的登录、服务浏览、资料填写、图片上传、OCR 识别、订单提交、支付、订单查询、物流履约、售后客服等相关服务。

本协议中的“我们”指本 H5 页面所展示的国际驾照翻译认证服务运营方及其必要的服务提供方。哈啰主要提供入口、WebView/H5 容器或来源识别能力；除页面另有明确说明外，订单、支付、履约、售后及本 H5 页面内的个人信息处理由我们负责。

请您在使用本服务前仔细阅读并理解本协议。您点击同意、勾选确认、提交资料、授权权限或继续使用需处理个人信息的功能，即表示您已充分阅读、理解并同意我们按照本协议处理您的个人信息。如您不同意本协议，您可以停止使用相关功能；不提供办理、支付、履约所必需的信息，可能导致我们无法向您提供对应服务。

## 二、敏感个人信息提示

在办理国际驾照翻译认证服务过程中，您可能需要提供身份证号、驾驶证号、驾驶证照片、证件照片、详细地址、精确定位、支付信息、包含人像的图片等敏感个人信息。上述信息一旦泄露、篡改或被非法使用，可能影响您的人身、财产安全或导致个人名誉、权益受损。

我们仅会在具有特定目的和充分必要性时处理敏感个人信息，并采取加密传输、权限控制、脱敏展示、操作审计等保护措施。您提交相关信息、上传图片、授权权限或勾选敏感个人信息处理同意，即视为您同意我们为本协议所述目的处理相关敏感个人信息。

如您拒绝提供办理所必需的敏感个人信息，可能无法完成资料识别、订单提交、审核、制作、发货或订单查询，但不影响您浏览不依赖该信息的页面内容。

## 六、个人信息保存和保护

我们将在实现本协议所述目的所必需的最短期限内保存您的个人信息。对于订单、支付、发票、物流、客服、交易争议、安全审计等信息，我们会按照法律法规、监管要求、业务履约和争议处理所需期限保存。保存期限届满后，我们将依法删除或匿名化处理您的个人信息；法律法规另有规定的除外。

原则上，我们会将境内收集和产生的个人信息存储在中华人民共和国境内。如因跨境服务、境外技术支持或其他业务需要向境外提供个人信息，我们将按照法律法规要求履行必要程序，并另行向您告知境外接收方、处理目的、处理方式、信息种类以及您行使权利的方式。

我们会采取合理可行的安全措施保护您的个人信息，包括但不限于 HTTPS 加密传输、访问权限控制、最小权限授权、敏感字段脱敏、文件访问隔离、日志审计、异常监控、员工保密管理和合作方安全管理。互联网环境并非绝对安全，如发生个人信息安全事件，我们将按照法律法规要求及时告知并采取补救措施。

## 七、您的个人信息权利

在符合法律法规规定的条件下，您可以通过本 H5 页面、订单页、客服入口或页面公示的联系方式，向我们行使以下权利：

1. 查询、复制您的个人信息。
2. 更正、补充不准确或不完整的个人信息。
3. 删除您的个人信息，但法律法规要求保存或业务履约仍必需的信息除外。
4. 撤回您已授予的同意或权限。
5. 注销账号或停止使用相关服务。
6. 获取本协议或个人信息处理规则的解释说明。
7. 对自动化决策、定向推荐或个性化展示提出异议；本 H5 页面如使用该等能力，会向您提供关闭或管理方式。

您撤回同意或关闭权限后，我们将不再基于该同意继续处理相应个人信息，但不影响撤回前已经进行的个人信息处理活动的效力。为保障安全，我们在响应您的权利请求前可能需要验证您的身份。我们将在收到并核验您的请求后尽快处理，一般不超过15个工作日；法律法规另有规定的，从其规定。

## 八、未成年人保护

本服务主要面向具有办理国际驾照翻译认证服务需求的成年人。如您为未满18周岁的未成年人，应在父母或其他监护人的陪同和同意下使用本服务。若您为未满14周岁的儿童，我们需要在取得您的父母或其他监护人同意后，方可处理您的个人信息。

如果监护人发现未成年人在未取得监护人同意的情况下向我们提供了个人信息，可通过本协议所列方式联系我们，我们将依法处理。
