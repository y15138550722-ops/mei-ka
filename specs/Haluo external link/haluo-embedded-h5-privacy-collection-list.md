# 哈啰APP内嵌H5页面隐私信息收集清单

**适用范围**：哈啰 App 内 WebView/H5 页面，用于用户登录、填写信息、地址、上传附件等场景。
**说明**：以下清单按“最小必要”原则整理，便于产品、法务、合规和研发评审使用。

## 1. 收集信息清单

| 信息类别       | 具体信息                                               | 收集目的                       | 是否必要           | 备注                                 |
| -------------- | ------------------------------------------------------ | ------------------------------ | ------------------ | ------------------------------------ |
| 账号标识       | 哈啰用户ID、登录态 token、unionId/openId 类标识        | 身份识别、登录态保持、业务关联 | 必要               | 不建议直接把手机号当唯一主键         |
| 基础账号信息   | 手机号、昵称、头像、实名状态                           | 登录、通知、展示用户信息       | 视业务而定         | 能少取就少取                         |
| 身份信息       | 姓名、身份证号、证件类型、证件有效期                   | 实名核验、资质审核             | 仅在业务必需时收集 | 属于高敏感信息，需单独明示           |
| 联系方式       | 手机号、备用手机号、邮箱                               | 结果通知、人工联系             | 视业务而定         | 未必需要全部收集                     |
| 地址信息       | 省市区、详细地址、地理位置、定位结果、收货/联系地址    | 服务履约、地址识别、派单/审核  | 常见必需项         | 如果用“当前位置”，涉及定位权限     |
| 附件信息       | 图片、PDF、视频、压缩包、文件名、大小、类型、EXIF 信息 | 资料提交、材料审核             | 按流程需要         | 图片可能包含敏感个人信息             |
| 设备信息       | 设备型号、系统版本、App 版本、WebView 信息、UA、分辨率 | 兼容性、风控、故障排查         | 必要               | 通常由客户端或浏览器自动产生         |
| 日志信息       | IP、访问时间、页面路径、点击记录、错误日志             | 安全审计、性能分析、问题定位   | 必要               | 建议做最小化保留                     |
| 网络与会话信息 | Cookie、localStorage、会话标识                         | 页面状态保持、登录态维持       | 必要               | 需在告知中写清                       |
| 位置权限数据   | GPS、基站、Wi-Fi 定位、选点坐标、附近地址              | 定位、地址选择、附近服务       | 仅在需要时         | 哈啰公开材料提到定位属于基础权限之一 |
| 存储权限数据   | 缓存图片、地图数据、上传临时文件                       | 图片/地图缓存、附件选择        | 仅在需要时         | 哈啰公开材料提到存储属于基础权限之一 |
| 摄像头数据     | 拍照图片、视频帧                                       | 扫码、拍照上传                 | 仅在需要时         | 若只支持从相册选取，可不申请         |
| 相册/文件数据  | 本地图片、文件内容、文件路径                           | 附件上传                       | 仅在需要时         | 上传前要做格式和大小校验             |
| 交易/业务结果  | 提交记录、审核状态、处理结果                           | 业务办理、结果回传             | 必要               | 按业务留存期限管理                   |

## 2. 建议补充的告知项

1. 信息用途要逐项写明，不要只写“用于提供服务”。
2. 敏感个人信息要单独弹窗或单独勾选同意。
3. 如果附件可能包含身份证、驾驶证、人脸照片，要把它明确列为敏感信息。
4. 如果不需要通讯录、麦克风、蓝牙等权限，建议明确不收集、不申请。
5. 页面中应明确说明收集、使用、保存、共享和删除规则。

## 3. 推荐的页面说明文案

> 本页面在哈啰 App 内提供服务办理能力，可能收集账号标识、地址信息、附件信息、设备信息、日志信息，以及在必要时收集定位、相机、存储和文件访问相关信息。我们仅会收集实现服务所必需的信息，并按法律法规及隐私政策进行处理。

## 4. 可直接放进评审文档的结论

哈啰 APP 内嵌 H5 页面应遵循最小必要原则收集信息。
若仅为页面展示，通常不需要额外权限。
若涉及登录、地址定位、附件上传、拍照等能力，则需按功能分别收集并单独告知用户。
