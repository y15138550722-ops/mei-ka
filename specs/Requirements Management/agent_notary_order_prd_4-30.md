## 1. 项目背景

当前公证订单在审核、制作、送审、公证处驳回后再次送审等流程中，公证处选择、生产端制作展示、材料制作状态与送审动作之间的联动不够清晰，导致制作人员无法准确获知应按哪个公证处要求维护材料，管理端送审时也缺少灵活调整能力。

同时，agent 客户端录单信息需要补充价格/时效、驾照有效期自定义、使用国家等字段，以满足不同业务场景。

## 2. 项目目标

1. 管理端审核通过时明确选择公证处，并保存为当前制作依据。
2. 送审弹窗默认带出审核通过时选择的公证处，同时允许送审时修改。
3. 送审时修改公证处后，需同步更新当前制作依据公证处。
4. 公证处驳回后再次送审时，允许选择与首次送审不同的公证处。
5. 更换公证处后，系统不强制重新制作材料，由工作人员人工维护材料。
6. 送审按钮仅在驾照官系统手动确认材料制作完成后展示。
7. 客户端支持三档价格/时效、驾照有效期自定义、使用国家必填。
8. 公证端预览审核返回时回到公证订单待审核列表。
9. 公证订单管理页订单记录按统一事件口径展示送审、审核、驳回、制作完成节点。
10. 公证端公证订单列表支持按优先级展示、筛选和排序，确保高优先级订单优先处理。

## 3. 角色说明

| 角色                    | 说明                                               |
| ----------------------- | -------------------------------------------------- |
| agent 管理端用户        | 审核订单、选择公证处、发起送审、修改送审公证处     |
| agent 客户端用户/录单员 | 创建公证订单、填写价格时效、驾照信息、使用国家     |
| 公证端用户              | 审核公证订单、驳回或通过                           |
| 生产端/驾照官制作人员   | 查看订单制作公证处要求，人工维护材料并标记制作完成 |
| 业务部门工作人员        | 配置三档价格/时效的档位名称、价格、服务时效        |

## 4. 已确认业务规则

| 问题                                                       | 结论                                               |
| ---------------------------------------------------------- | -------------------------------------------------- |
| 使用国家是否必填                                           | 必填                                               |
| 三档价格/时效由谁配置                                      | 业务部门工作人员配置                               |
| 审核时选择的是公证处还是公证处模板                         | 选择公证处                                         |
| 公证处与公证处模板是否需要一一对应                         | 不需要一一对应                                     |

| 材料齐全状态如何判断                                       | 根据公证处所需附件配置进行校验，看送审时材料全不全 |

| 相同优先级订单如何排序                                     | 按推送至公证处时间升序，先推送的订单排在前         |

## 5. 功能需求

## 5.1 agent 管理端

### 5.1.1 订单审核通过时选择公证处

入口：

公证订单管理页面 > 订单审核页面

需求说明：

1. 管理端用户点击“通过”时，系统需弹出或展示“选择公证处”的控件。
2. 用户必须选择一个公证处后，才允许审核通过。
3. 审核通过后，所选公证处需保存为当前制作依据，并同步给后续制作、送审和订单记录逻辑读取。
4. 公证处与模板不要求一一对应，系统不需要强制维护公证处与模板的固定映射关系。

字段建议：

| 字段                                      | 所属对象 | 说明                       |
| ----------------------------------------- | -------- | -------------------------- |
| `audit_selected_notary_office_id`       | 订单     | 审核通过时选择的公证处 ID  |
| `audit_selected_notary_office_name`     | 订单     | 审核通过时选择的公证处名称 |
| `production_display_notary_office_id`   | 订单     | 当前制作依据公证处 ID      |
| `production_display_notary_office_name` | 订单     | 当前制作依据公证处名称     |
| `audit_pass_time`                       | 订单     | 审核通过时间               |
| `audit_operator_id`                     | 订单     | 审核人 ID                  |

验收标准：

- 点击“通过”但未选择公证处时，系统提示“请选择公证处”。
- 审核通过后，系统保存对应公证处信息，后续送审弹窗默认带出该公证处。
- 公证处信息同步生产端失败时，需提示用户并记录失败原因。

### 5.1.2 审核通过后同步公证处至送审弹窗

需求说明：

1. 管理端审核通过时选择的公证处，需要作为默认值同步到“送审”弹窗中。
2. 送审弹窗中允许修改公证处。
3. 若用户不修改，则按默认公证处送审。
4. 若用户修改，则按最新选择的公证处送审。
5. 送审时修改公证处后，需同步更新当前制作依据公证处。

验收标准：

- 送审弹窗打开时，默认选中审核通过时选择的公证处。
- 用户可切换公证处。
- 送审记录中保存本次实际送审公证处。
- 送审公证处被修改后，当前制作依据公证处同步更新为最新公证处。

### 5.1.3 被公证处驳回后再次送审允许更换公证处

需求说明：

1. 订单送审至公证处后，如被公证处驳回，管理端订单回到待制作列表。
2. 再次送审时，管理端用户可以选择与第一次不同的公证处。
3. 如选择新公证处，系统需同步更新当前制作依据公证处。
4. 更换公证处后，系统不强制重新制作材料，也不自动重置材料制作状态。
5. 如新公证处涉及不同材料要求，由工作人员在生产端或相关材料维护页面人工维护材料。
6. 每次送审需形成独立送审记录，保留历史公证处、送审时间、驳回原因、再次送审公证处等信息。

验收标准：

- 被驳回订单可再次送审。
- 再次送审时可选择不同公证处。
- 更换公证处后，当前制作依据公证处同步更新。
- 系统不强制触发重新制作材料流程。
- 历史送审记录不可被覆盖。

### 5.1.4 送审按钮显示逻辑调整

需求说明：

1. 管理端右侧“送审”按钮仅在驾照官生产端手动确认该订单“制作完成”后展示。
2. 如果材料未制作完成，管理端不展示“送审”按钮。
3. 驾照官生产端工作人员点击“制作完成”后，系统同步材料完成状态至管理端。
4. 管理端根据材料状态实时或刷新后更新按钮显示。
5. 材料是否齐全不由系统自动按上传完整性判断，以生产端工作人员手动确认为准。

状态建议：

| 材料状态   | 触发方式                           | 管理端送审按钮                                   |
| ---------- | ---------------------------------- | ------------------------------------------------ |
| 未制作     | 初始状态或人工设置                 | 不展示                                           |
| 制作中     | 生产端处理材料                     | 不展示                                           |
| 制作完成   | 生产端工作人员手动点击“制作完成” | 展示                                             |
| 已送审     | 管理端完成送审                     | 按现有逻辑展示或隐藏                             |
| 公证处驳回 | 公证端驳回                         | 允许再次送审，是否展示仍以生产端制作完成状态为准 |

验收标准：

- 驾照官未手动确认制作完成时，管理端看不到送审按钮。
- 驾照官标记制作完成后，管理端可看到送审按钮。
- 材料状态同步异常时需有日志记录。

### 5.1.5 公证订单管理页订单记录展示规则

需求说明：

1. 订单记录按记录产生时间正序展示。
2. 每条订单记录分两行展示：
   - 第一行：事件名称。
   - 第二行：事件时间 + 公证处名称。
3. 事件时间使用真实触发时间，不允许随机生成。
4. 时间按北京时间展示，格式为 `YYYY-MM-DD HH:mm:ss`。
5. 公证处审核通过与制作中合并为一个事件：“审核通过--制作中”。
6. 公证处制作完成事件展示为：“制作完成”。
7. 公证处审核驳回事件展示为：“审核驳回”。
8. “审核通过--制作中”“制作完成”“审核驳回”三个事件名称中不展示“公证处”文案，但第二行仍展示对应公证处名称。
9. 被公证处驳回的订单回到待制作列表后，订单记录仍需展示“审核驳回”事件和驳回时间，并显示“送审”按钮支持再次送审。

订单记录展示口径：

| 触发节点       | 管理页订单记录事件 | 第二行展示            | 排序           |
| -------------- | ------------------ | --------------------- | -------------- |
| 点击确定送审   | 已送审-审核中      | 北京时间 + 公证处名称 | 按触发时间正序 |
| 公证处审核通过 | 审核通过--制作中   | 北京时间 + 公证处名称 | 按触发时间正序 |
| 公证处审核驳回 | 审核驳回           | 北京时间 + 公证处名称 | 按触发时间正序 |
| 公证处制作完成 | 制作完成           | 北京时间 + 公证处名称 | 按触发时间正序 |

验收标准：

- 订单记录中不出现“公证处审核通过--制作中”“公证处制作完成”“公证处审核驳回”这三个旧事件文案。
- 对应事件应展示为“审核通过--制作中”“制作完成”“审核驳回”。
- 被驳回订单在待制作状态下仍能看到“审核驳回”记录，并可再次送审。
- 再次送审产生的新记录追加在历史记录后，不覆盖原历史记录。

### 5.1.6 公证订单审核页面资料修改规则

入口：

公证订单管理页面 > 订单审核页面 > 修改

需求说明：

1. 管理端用户点击“修改”后，驾照信息与收货信息进入可编辑状态。
2. 当“有效年限”选择 `自定义` 时，联动展示“终止日期”日期选择器；查看态也仅在有效年限为 `自定义` 时展示“终止日期”。
3. 当“有效年限”选择非 `自定义` 时，“终止日期”字段不在页面展示；保存时可按有效起始日期与有效年限计算或写空。
4. 当“有效年限”选择 `自定义` 但未选择“终止日期”时，禁止保存并提示“请选择终止日期”。
5. 保存资料修改后，需更新订单 `updatedAt` 并写入资料修改日志。

字段建议：

| 业务字段 | API/数据建议字段     | 当前前端订单字段          | 修改态控件 | 说明                                   |
| -------- | -------------------- | ------------------------- | ---------- | -------------------------------------- |
| 终止日期 | `license_end_date` | `licenseValidUntilDate` | 日期选择器 | 仅有效年限为 `自定义` 时展示并可编辑 |

验收标准：

- 有效年限选择 `自定义` 后展示“终止日期”日期选择器。
- 有效年限不为 `自定义` 时，查看态和修改态均不展示“终止日期”字段。
- 自定义终止日期为空时保存失败，并提示“请选择终止日期”。

## 5.2 agent 客户端

### 5.2.1 价格/时效调整为三档

需求说明：

1. agent 用户端价格/时效调整为三档配置。
2. 每档价格对应一个服务时效。
3. 用户录单时选择某一档，系统自动带出对应价格和时效。
4. 三档内容需支持后台配置，不允许前端写死。
5. 三档价格/时效的档位名称、价格、服务时效由业务部门工作人员维护。

示例：

| 档位 | 价格 | 时效       |
| ---- | ---- | ---------- |
| 标准 | ¥X  | X 个工作日 |
| 加急 | ¥X  | X 个工作日 |
| 特急 | ¥X  | X 个工作日 |

字段建议：

| 字段                | 所属对象 | 说明             |
| ------------------- | -------- | ---------------- |
| `price_tier_id`   | 订单     | 价格/时效档位 ID |
| `price_tier_name` | 订单     | 档位名称         |
| `service_price`   | 订单     | 服务价格         |
| `service_time`    | 订单     | 服务时效         |

验收标准：

- 客户端展示业务部门配置的三档价格/时效。
- 用户只能选择一档。
- 订单保存后记录所选档位、价格、时效。
- 业务部门调整配置后，新订单按最新配置展示和下单。

### 5.2.2 驾照有效期增加自定义终止日期

需求说明：

1. “有效起始日期”字段保持不变。
2. “有效期”选项中新增“自定义”。
3. 在“有效期”下一行新增“终止日期”字段。
4. 当“有效期”选择“自定义”时，录单员可自行选择终止日期。
5. 当“有效期”选择非自定义选项时，终止日期可由系统自动计算或按现有逻辑处理。
6. 自定义终止日期不得早于有效起始日期。
7. 当“有效期”选择“自定义”但未选择终止日期时，禁止提交订单并提示“请选择终止日期”。

字段建议：

| 字段                   | 所属对象 | 说明         |
| ---------------------- | -------- | ------------ |
| `license_start_date` | 订单     | 有效起始日期 |
| `validity_type`      | 订单     | 有效期类型   |
| `license_end_date`   | 订单     | 终止日期     |

验收标准：

- 有效期下拉中包含“自定义”。
- 选择“自定义”后，终止日期可编辑。
- 选择“自定义”但未选择终止日期时，提交订单需提示“请选择终止日期”。
- 终止日期早于起始日期时禁止提交。

### 5.2.3 公证订单录单时增加使用国家

需求说明：

1. 公证订单录单页面，在“语言”字段下方增加“使用国家”字段。
2. 使用国家为必填字段，控件采用普通文本输入框，支持录单员手动输入国家或地区名称。
3. 未填写使用国家时，禁止提交订单，并提示“请选择使用国家”。
4. 使用国家需保存至订单详情，并同步至管理端、生产端、公证端相关详情页展示。
5. 当前前端订单对象字段使用 `useCountry`；接口或持久化字段建议映射为 `use_country`。

字段建议：

| 字段                             | 所属对象 | 说明                                      |
| -------------------------------- | -------- | ----------------------------------------- |
| `language`                     | 订单     | 公证语言                                  |
| `use_country` / `useCountry` | 订单     | 使用国家，必填；前端字段为 `useCountry` |

验收标准：

- 录单页面语言下方展示“使用国家”。
- 使用国家以输入框形式展示，placeholder 为“请输入使用国家”。
- 使用国家未填写时，提交订单需提示“请选择使用国家”。
- 提交订单后，订单详情可查看使用国家。
- 后续审核、制作、送审环节可读取该字段。

## 5.3 agent 公证端

### 5.3.1 预览审核返回逻辑修改

需求说明：

1. 公证端用户从“公证订单待审核列表”进入预览审核页面。
2. 点击返回时，应返回“公证订单待审核列表”。
3. 不应返回全部订单列表。
4. 如用户从其他列表进入预览审核页面，则返回来源列表。

验收标准：

- 从待审核列表进入详情，点击返回后回到待审核列表。
- 列表筛选状态、分页状态尽量保持。
- 不跳转至全部列表。

### 5.3.2 公证处公证订单列表优先级展示、筛选与排序

入口：

公证处公证订单页面 > 公证订单列表

需求说明：

1. 公证处-公证订单列表新增“优先级”列，展示当前订单的办理优先级。
2. 优先级展示值为：`紧急`、`优先`、`正常`。
3. 筛选项新增“优选筛选”（即优先级筛选），支持按上述三档优先级过滤订单。
4. 列表默认按优先级从高到低排序，即：`紧急` 优先，其次 `优先`，最后 `正常`。
5. 在相同优先级下，再按“推送至公证处时间”升序排序，先推送的订单排在前。
6. 若推送至公证处时间缺失，则回退使用订单创建时间；若仍缺失，则按订单号升序作为兜底排序。

字段建议：

| 字段                  | 所属对象 | 说明                                           |
| --------------------- | -------- | ---------------------------------------------- |
| `process_type`      | 订单     | 办理优先级/办理类型原始值                      |
| `process_type_id`   | 订单     | 办理优先级档位 ID                              |
| `process_type_name` | 订单     | 办理优先级展示名称：紧急办理/优先办理/正常办理 |
| `pushed_at`         | 送审记录 | 推送至公证处时间，用于列表排序                 |

验收标准：

- 公证处订单列表可看到“优先级”列。
- “优选筛选”可按紧急、优先、正常过滤列表。
- 列表默认按优先级由高到低排序。
- 同优先级订单按推送至公证处时间升序展示。
- 推送时间相同或缺失时有稳定的兜底排序结果。

## 5.4 agent 生产端/驾照官系统

### 5.4.1 制作公证处信息同步与列表展示边界

需求说明：

1. 系统需保留管理端当前选择/送审的公证处信息，作为制作依据和流程追踪数据。
2. 首次制作依据来自管理端审核通过时选择的公证处。
3. 管理端送审时如修改公证处，需同步更新当前制作依据公证处。
4. 公证处驳回后再次送审时如更换公证处，需同步更新当前制作依据公证处。
5. 公证处与模板不要求一一对应，系统不需要强制维护固定映射。

列表字段：

| 列名     | 说明                   |
| -------- | ---------------------- |
| 制作模板 | 不在公证处订单列表展示 |

验收标准：

- 系统仍保存当前制作依据公证处，供订单详情、材料制作或后续流程读取。
- 管理端修改送审公证处后，当前制作依据公证处同步更新。
- 信息为空时需支持异常日志排查。

### 5.4.2 生产端手动确认制作完成

需求说明：

1. 驾照官生产端需支持工作人员对公证订单手动点击“制作完成”。
2. 点击“制作完成”后，订单材料状态更新为“制作完成”。
3. 材料状态同步至管理端后，管理端才展示“送审”按钮。
4. 系统不根据材料上传完整性自动判断材料齐全。

验收标准：

- 生产端工作人员可手动标记订单制作完成。
- 标记完成后，管理端订单可出现送审按钮。
- 未标记完成时，管理端不展示送审按钮。

## 6. 核心流程

### 6.1 首次审核与制作流程

1. 客户端录入公证订单，填写语言、使用国家、驾照有效期、价格/时效档位等信息。
2. 管理端进入订单审核页面。
3. 管理端点击“通过”。
4. 系统要求选择公证处。
5. 审核通过。
6. 公证处信息推送至驾照官生产端。
7. 系统保存该公证处作为当前制作依据。
8. 驾照官制作人员按该公证处要求人工维护材料。
9. 驾照官制作人员手动点击“制作完成”。
10. 管理端展示“送审”按钮。
11. 管理端打开送审弹窗，默认带出审核时选择的公证处。
12. 管理端确认或修改公证处后送审。
13. 如送审时修改公证处，当前制作依据公证处同步更新。

### 6.2 公证处驳回后再次送审流程

1. 公证处驳回订单。
2. 管理端订单回到待制作列表。
3. 管理端订单记录展示“审核驳回”和驳回时间。
4. 管理端展示“送审”按钮，支持再次送审。
5. 系统允许重新选择公证处。
6. 如更换公证处，当前制作依据公证处同步更新为新公证处。
7. 系统不强制重新制作材料，由工作人员根据新公证处要求人工维护材料。
8. 满足送审条件后，管理端再次送审。
9. 系统形成新的送审记录。

## 9. 异常处理

1. 公证处未选择：禁止审核通过。
2. 公证处信息同步生产端失败：提示用户并记录日志，可支持重试。
3. 材料未制作完成：管理端不展示送审按钮。
4. 更换公证处后材料是否需要调整：系统不强制重做，由工作人员人工维护。
5. 生产端制作完成状态同步失败：记录日志，并允许重试同步。
6. 公证端返回来源丢失：默认返回待审核列表。
7. 使用国家未填写：禁止提交订单。
8. 自定义终止日期早于有效起始日期：禁止提交。
9. 管理端审核修改时有效年限为自定义但终止日期为空：禁止保存并提示“请选择终止日期”。

## 10. 上线验收清单

- 管理端审核通过必须选择公证处。
- 审核时选择的是公证处，不是公证处模板。
- 公证处与模板不要求一一对应。
- 系统保留当前制作依据公证处，供订单详情、材料制作或后续流程读取。
- 送审弹窗默认带出审核时选择的公证处，并允许修改。
- 送审时修改公证处后，当前制作依据公证处同步更新。
- 公证处驳回后可再次送审，并可更换公证处。
- 公证处驳回后管理端订单回到待制作列表，订单记录展示“审核驳回”和驳回时间。
- 订单记录中的“审核通过--制作中”“制作完成”“审核驳回”事件名称不展示“公证处”文案，第二行展示时间 + 公证处名称。
- 更换公证处后不强制重新制作材料，由工作人员人工维护。
- 生产端工作人员手动点击“制作完成”后，管理端才展示送审按钮。
- 客户端价格/时效展示三档，配置由业务部门工作人员维护。
- 客户端驾照有效期支持自定义终止日期。
- 客户端语言下方新增使用国家，且使用国家必填。
- 管理端公证订单审核修改页有效年限为下拉选择，且仅自定义时展示终止日期。
- 公证端预览审核返回公证订单待审核列表。
- 公证处-公证订单列表新增“优先级”列，展示紧急办理、优先办理、正常办理。
- 公证处-公证订单列表新增“优选筛选”，可按紧急办理、优先办理、正常办理过滤。
- 公证处-公证订单列表按优先级排序：紧急办理在前、优先办理其次、正常办理最后。
- 同优先级订单按推送至公证处时间升序排序，先推送的订单排在前。
