# 小语种宣誓翻译需求

## 自动翻译

- **当前痛点：** 依赖外部网页工具\(金山词霸和豆包\)，需要人工去进行频繁切换页面翻译、不稳定、效率低、时间长、而且没有 API 去让我们接入。

- **方案：** 基本逻辑与网页翻译类似，但使用我们自己总结的独立模板和翻译规则。

    - 订单进入到驾照官系统后，系统自动进行翻译

    - 集成自动翻译API：对输入的中文文本，用我们自己的翻译 API 规则进行精准翻译。对于固定翻译字段建立标准库，确保翻译一致性。

    - 自动填充与生成： 识别和翻译的结果自动填充到对应输入框模的位置。

    - 调用提前预设好的宣誓翻译模板库进行翻译和排版。

    - 人工校对： 对自动翻译后的订单进行人工核对，这一步是必须的，并且人工需要去把标准词提交到翻译库里面

### **法语翻译**

地址翻译: 只要不是首个字母，专有名词除外，全部小写比如村，路，省，市 等

N°102, village de Hujiahui, rue de Gaoqiao, district de Huangyan, ville de Taizhou, province du Zhejiang 

\(浙江省台州市黄岩区高桥街道胡家灰村102号\)



### **德语翻译:**

地址翻译: 首字母全部大写, 后面需要加上VR China, 省/市/区 需要放在地名前面, 路、街道放地名后面

Zimmer 207, Gebäude 7, Nr\. 631 Huanghesan Straße, Bezirk Bincheng, Stadt Binzhou, Provinz Shandong, VR China

\(山东省滨州市滨城区黄河三路631号7号楼207室\)



### **西班牙翻译 **

地址翻译: 首字母全部大写

No\. 102, Aldea de Hujiahui, Calle Gaoqiao, Distrito de Huangyan, Ciudad de Taizhou, Provincia de Zhejiang

\(浙江省台州市黄岩区高桥街道胡家灰村102号\)



### **意大利翻译：** 

地址翻译： 只要不是首个字母，专有名词除外，全部小写

N\. 102, villaggio di Hujiahui, via Gaoqiao, distretto di Huangyan, città di Taizhou, provincia di Zhejiang

\(浙江省台州市黄岩区高桥街道胡家灰村102号\)
