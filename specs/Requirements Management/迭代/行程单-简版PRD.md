# 公证订单管理-导出行程单-简版PRD

> 模块：管理端 / 公证订单管理
> 版本：v1.0
> 更新时间：2026-05-27

## 1. 背景

公证订单在审核过程中，运营人员需要为部分订单生成标准化行程单，用于后续材料整理、核验和导出使用。当前管理端缺少统一的行程单生成与导出能力，存在人工整理成本高、内容格式不统一、修改不方便的问题。

因此，需要在管理端公证订单管理中新增“导出行程单”能力，支持基于订单信息自动生成行程单，并可在线编辑后导出 PDF。

## 2. 目标

- 在公证订单管理的“订单审核/查看审核”页面新增“导出行程单”按钮
- 点击后基于导出模板生成 Word 行程单
- 支持在线编辑行程单内容
- 支持按最终编辑结果导出 PDF
- 提升运营处理效率，保证导出材料格式统一

## 3. 使用角色

- 运营人员
- 管理员

以上角色在可访问公证订单审核详情页的前提下，可使用导出行程单功能。

## 4. 功能范围

### 4.1 页面入口

在“管理端 - 公证订单管理 - 订单审核 / 查看审核”页面增加“导出行程单”按钮。

### 4.2 功能流程

1. 运营人员进入公证订单审核详情页
2. 点击“导出行程单”按钮
3. 系统根据导出模板生成该订单对应的行程单内容
4. 系统打开可在线编辑的行程单预览页
5. 运营人员可对内容进行修改
6. 点击“导出 PDF”后，系统按最终编辑结果导出 PDF 文件

## 5. 核心功能说明

### 5.1 模板生成

- 系统需基于预设的行程单模板生成 Word 文档内容
- 模板中的字段由订单数据和系统规则自动填充
- 若部分字段无法命中订单信息，则按默认规则兜底生成

### 5.2 在线编辑

- 生成后的行程单需支持在线编辑
- 运营人员可修改文本内容
- 最终导出的 PDF 内容必须与当前编辑后的内容一致

### 5.3 PDF 导出

- 支持将最终确认后的行程单导出为 PDF
- 导出文件命名建议包含订单号、乘客姓名、行程单标识

## 6. 字段生成规则

| 字段 | 生成规则 |
| --- | --- |
| 订单编号 | 随机生成航空公司订单编号 |
| 乘客 | 根据公证订单中展示姓名生成 |
| 发行日期 | 根据订单下单时间往前推 7-30 天，格式为 `xxxx年x月x日` |
| 发行航空公司 | 随机展示航空公司，如中国国际航空、中国东方航空、中国南方航空、四川航空、海南航空、厦门航空、首都航空、成都航空等 |
| 日期 | 根据订单下单时间后 15-90 天内随机生成，格式为 `xxxx年x月x日` |
| 航空公司PNR | 根据发行航空公司生成对应航空公司 PNR |
| 航班 | 根据发行航空公司生成对应航班 |
| 出发时间 / 航站楼 | 根据订单中的发证地区字段，生成对应省级机场的出发时间、机场信息、航站楼信息 |
| 到达时间 / 航站楼 | 根据订单中的使用国家字段，生成对应到达时间、机场信息、航站楼信息 |
| 舱位 | 固定为“经济舱” |
| 航班状态 | 固定为“准点” |
| 付款详情 | 根据飞行日期中的出发和到达信息生成人民币、税费、总计 |
| 通知 | 固定文案 |

## 7. 业务规则

- 同一订单首次生成行程单后，若未重新触发生成，编辑内容应以当前页面内容为准
- 在线编辑仅影响当前导出结果，不改变原始订单数据
- PDF 导出内容以最终编辑内容为准，不以初始模板内容为准
- 航空公司、航班号、PNR、日期等字段可按系统规则随机生成，但需满足基本格式要求
- 出发机场需优先匹配发证地区对应的省级机场
- 到达机场需优先匹配使用国家对应的国家/城市机场信息

## 8. 异常与兜底

- 若订单缺少展示姓名，则乘客字段提示为空或使用默认占位
- 若发证地区无法匹配机场，则使用默认省级机场兜底
- 若使用国家无法匹配到达机场，则使用默认国际机场兜底
- 若模板生成失败，需提示“行程单生成失败，请稍后重试”
- 若 PDF 导出失败，需提示“PDF 导出失败，请稍后重试”

## 9. 非功能要求

- 页面操作应简洁直观，适合运营快速处理
- 行程单预览内容排版需接近正式出行单据样式
- 在线编辑过程应尽量流畅，避免明显卡顿
- 导出的 PDF 应保持版式完整，不出现字段错位、截断、乱码

## 10. 验收标准

### 10.1 功能验收

- 在公证订单管理“订单审核/查看审核”页面可看到“导出行程单”按钮
- 点击按钮后可成功生成行程单预览内容
- 预览内容基于模板自动带出字段
- 支持在线编辑内容
- 点击“导出 PDF”后可导出 PDF 文件
- 导出的 PDF 内容与编辑后的最终内容一致

### 10.2 规则验收

- 发行日期符合“下单时间前 7-30 天”规则
- 出行日期符合“下单时间后 15-90 天”规则
- 舱位固定显示“经济舱”
- 航班状态固定显示“准点”
- 出发信息与发证地区逻辑一致
- 到达信息与使用国家逻辑一致

## 11. 本期不包含

- 行程单编辑结果回写订单
- 行程单历史版本管理
- 多乘客、多航段复杂排版
- 后台自定义维护航空公司、机场、通知文案规则
