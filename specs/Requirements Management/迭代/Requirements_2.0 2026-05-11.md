## 1. 背景与目标

### 1.1 背景

当前公证订单在生产端制作完成后，仍依赖人工在管理端触发送审，且送审前需要人工确认不同公证处所需材料是否齐全。随着公证处数量、材料规则和订单量增加，人工送审容易出现以下问题：

- 制作完成后未及时送审，影响公证审核时效。
- 不同公证处材料要求不同，人工抓取材料存在遗漏风险。
- 被公证处审核驳回后，需要支持再次送审，且可能需要改送其他公证处。
- 管理端与生产端材料分散，送审时需要统一抓取并形成完整送审包。

同时，agent 管理端导出的委托书中，委托人签名样式需要支持更自然的版式变化，避免签名呈现过于统一。

### 1.2 目标

1. 生产端/驾照官系统在公证订单“未制作”状态下，制作人员点击“制作完成”后，系统自动根据订单选择的公证机构发起送审。
2. 自动送审前，系统按目标公证处的材料要求，统一抓取管理端与生产端已有材料。
3. 公证端接收送审订单后，支持“审核通过 > 制作 > 制作完成”和“审核驳回”两条处理路径。
4. 被公证处审核驳回的订单回到管理端待制作列表，运营人员可再次送审。
5. 再次送审时支持修改送审公证处，并按本次选择的公证处判定所需材料是否齐全。
6. 管理端导出委托书时，委托人签名支持放大、缩小、无规则拉伸等样式变化。

### 1.3 非目标

- 不在本期实现真实外部公证处系统 API 对接，若当前系统为模拟公证端，则按内部公证端数据流转实现。
- 不在本期实现材料内容的 OCR 真伪校验。
- 不在本期实现公证处材料模板的复杂版本审批流程。
- 不在本期改变委托书正文模板内容，仅调整委托人签名呈现样式。

## 3. 业务范围

### 3.1 In Scope

- 生产端制作完成后自动送审。
- 按公证处材料要求抓取管理端与生产端材料。
- 明确不同公证处材料清单由业务部门提供，系统按配置或清单执行抓取。
- 自动送审失败时的状态、提示与日志。
- 驳回订单在管理端待制作列表展示“送审”按钮。
- 管理端再次送审时可修改公证处。
- 每次送审形成独立送审记录。
- 委托书导出时委托人签名样式随机化处理。

### 3.2 Out of Scope

- 公证处后台材料配置页面的新建或重构，若已有配置则复用。
- 对签名图片进行身份识别、笔迹识别或防伪认证。
- 对历史已导出的委托书文件进行批量重生成。

## 4. 核心状态与流程

### 4.1 公证订单状态建议

| 状态                                     | 说明                         | 可执行动作               |
| ---------------------------------------- | ---------------------------- | ------------------------ |
| `not_made` / 未制作                    | 生产端尚未完成材料制作       | 生产端制作完成           |
| `material_completed` / 制作完成        | 生产端已确认材料制作完成     | 系统自动抓取材料并送审   |
| `submitting_to_notary` / 送审中        | 系统正在抓取材料并推送公证处 | 等待送审结果             |
| `pending_notary_review` / 公证处待审核 | 公证端已接收订单             | 公证端审核通过、审核驳回 |
| `notary_in_production` / 公证处制作中  | 公证端审核通过后进入制作     | 公证端制作完成           |
| `notary_completed` / 公证处制作完成    | 公证处已完成制作             | 后续物流或归档流程       |
| `notary_rejected` / 公证处审核驳回     | 公证处驳回订单               | 管理端再次送审           |

### 4.2 首次自动送审流程

1. 公证订单处于“未制作”状态。
2. 生产端/驾照官系统制作人员完成材料维护。
3. 制作人员点击“制作完成”。
4. 系统读取订单当前选择的公证机构。
5. 系统读取目标公证处所需材料清单。
6. 系统按材料清单从管理端与生产端统一抓取图片、Word、PDF 文件。
7. 系统生成本次送审材料清单，记录材料名称、文件格式、抓取来源和是否必需。
8. 系统校验必需材料是否齐全。
9. 材料齐全时，系统生成送审包并自动送审至对应公证处。
10. 公证端生成待审核订单。
11. 管理端订单记录同步展示“已送审/公证处待审核”。

### 4.3 公证端审核流程

路径 A：审核通过

1. 公证端审核人员进入待审核订单。
2. 查看送审材料。
3. 点击“审核通过”。
4. 订单进入“制作中”。
5. 公证端制作人员完成制作后点击“制作完成”。
6. 订单进入“公证处制作完成”。

路径 B：审核驳回

1. 公证端审核人员进入待审核订单。
2. 填写驳回原因。
3. 点击“审核驳回”。
4. 公证端订单进入“已驳回”。
5. 管理端订单回到“公证订单管理 > 待制作列表”。
6. 管理端展示“送审”按钮，支持再次送审。

### 4.4 驳回后再次送审流程

1. 公证处审核驳回订单。
2. 管理端待制作列表展示该订单，并显示“送审”按钮。
3. 运营人员点击“送审”。
4. 系统打开送审弹窗，默认带出上次送审公证处。
5. 运营人员可保持原公证处，也可修改为其他公证处。
6. 系统按本次选择的公证处重新读取材料要求。
7. 系统重新抓取管理端与生产端材料。
8. 材料满足要求后，生成新的送审记录并推送到对应公证处。
9. 公证端生成新的待审核任务或更新当前订单的待审核轮次。
10. 历史驳回原因和历史送审记录保留，不被覆盖。

## 5. 功能需求

## 5.1 agent 生产端/驾照官系统

### 5.1.1 制作完成触发自动送审

入口：公证订单列表/详情 > 未制作订单 > 制作完成

需求说明：

1. 仅“未制作”或等价待制作状态的公证订单允许点击“制作完成”。
2. 制作人员点击“制作完成”后，系统先更新材料制作状态为“制作完成”。
3. 系统自动触发送审任务，不需要制作人员跳转到管理端手动送审。
4. 自动送审目标公证处取订单当前选择的公证机构。
5. 若订单未选择公证处，制作完成可以保存，但自动送审失败，并提示“订单未选择公证处，请在管理端补充后重新送审”。
6. 自动送审成功后，生产端订单状态展示为“已送审”或“公证处待审核”。

验收标准：

- 制作人员点击“制作完成”后，系统自动发起送审。
- 已选择公证处且材料齐全时，公证端可看到待审核订单。
- 未选择公证处时，不生成公证端待审核订单，并记录失败原因。
- 重复点击“制作完成”不会生成重复送审记录。

### 5.1.2 送审前材料自动抓取

需求说明：

1. 系统按目标公证处材料配置获取必需材料与可选材料清单。
2. 不同公证处材料清单由业务部门提供，系统需支持按公证处维度读取不同抓取规则。
3. 本期抓取文件格式限定为图片、Word、PDF；其他格式不纳入自动送审包，除非后续公证处材料清单另行补充。
4. 材料来源包括管理端上传/维护材料与生产端制作材料。
5. 同一材料在多个来源存在时，按配置优先级或最新更新时间选择送审版本。
6. 必需材料缺失时，自动送审失败，订单进入“送审失败”或保持“制作完成待送审”状态。
7. 送审失败原因需明确展示缺失材料名称。
8. 可选材料缺失不阻断送审，但需在送审记录中标记未提供。

材料抓取建议：

| 文件格式  | 材料类型                                                                               | 抓取来源 |
| --------- | -------------------------------------------------------------------------------------- | -------- |
| .png/.jpg | 驾驶证正面、驾驶证背面、副页正面、副页背面、<br />证件正面、证件背面、电子驾照、签名图 | 管理端   |
| .word     | 【公证处】委托书、外事办委托书                                                         | 管理端   |
| .word     | 公证词翻译、驾照页翻译                                                                 | 生产端   |
| .pdf      | 扫描件                                                                                 | 管理端   |
| .pdf      | 公证书                                                                                 | 生产端   |

材料规则说明：

1. `.png/.jpg` 图片类材料用于证件、驾驶证、电子驾照和签名图等基础附件。
2. 管理端 Word 材料包括【公证处】委托书、外事办委托书等由管理端生成或维护的文书。
3. 生产端 Word 材料包括公证词翻译、驾照页翻译等制作人员产出的文书。
4. 管理端 PDF 材料包括扫描件。
5. 生产端 PDF 材料包括公证书。
6. 不同公证处需要抓取哪些文件、哪些为必需项、哪些为可选项，以业务部门提供的公证处材料清单为准。

验收标准：

- 系统能同时抓取管理端和生产端材料。
- 不同公证处能按不同材料清单抓取材料。
- 业务部门提供不同公证处抓取文件材料后，系统能按清单执行抓取和必需项校验。
- 必需材料缺失时自动送审被阻断，并显示缺失项。
- 送审记录中可查看本次抓取到的材料清单。
- 送审记录中的每个材料需展示文件格式、材料名称、抓取来源和抓取结果。

## 5.2 agent 公证端

### 5.2.1 接收送审订单

需求说明：

1. 公证端只接收送审给当前公证处的订单。
2. 自动送审成功后，订单进入公证端“待审核”列表。
3. 列表需展示订单号、客户信息、产品信息、送审时间、送审来源、材料数量。
4. 同一订单多次送审时，应能区分送审轮次。
5. 历史驳回订单再次送审后，应重新进入待审核列表。

验收标准：

- 生产端制作完成并自动送审成功后，公证端待审核列表出现对应订单。
- 改送其他公证处时，仅新的目标公证处可看到该轮送审订单。
- 再次送审不会覆盖历史审核记录。

### 5.2.2 审核通过与制作完成

需求说明：

1. 公证端审核人员可在待审核订单详情查看送审材料。
2. 点击“审核通过”后，订单进入“制作中”。
3. 制作中订单支持公证端制作人员点击“制作完成”。
4. 制作完成后，同步管理端和生产端订单记录。

验收标准：

- 待审核订单可执行“审核通过”。
- 审核通过后订单从待审核列表移入制作中列表。
- 制作完成后订单进入已完成状态。
- 管理端订单记录展示审核通过和制作完成节点。

### 5.2.3 审核驳回

需求说明：

1. 公证端审核人员可点击“审核驳回”。
2. 审核驳回必须填写驳回原因。
3. 驳回后，公证端订单进入“已驳回”。
4. 驳回结果、驳回原因、驳回时间、驳回人需同步给管理端。
5. 管理端订单回到待制作列表，并展示“送审”按钮。

验收标准：

- 未填写驳回原因时不能提交驳回。
- 驳回后管理端可看到驳回原因。
- 驳回后管理端可再次送审。
- 公证端保留历史驳回记录。

## 5.3 agent 管理端

### 5.3.1 驳回订单再次送审

入口：订单中心 > 公证订单管理 > 待制作列表

需求说明：

1. 被公证处审核驳回的订单回到待制作列表。
2. 操作列展示“送审”按钮。
3. 点击“送审”后打开送审弹窗。
4. 弹窗默认带出上次送审公证处。
5. 运营人员可修改送审公证处。
6. 点击确认送审后，系统按本次选择的公证处抓取材料并送审。
7. 再次送审成功后，订单进入“公证处待审核”。

验收标准：

- 公证处驳回订单后，管理端待制作列表展示该订单。
- 该订单操作列展示“送审”按钮。
- 再次送审时可以修改公证处。
- 改送公证处后，订单进入新公证处待审核列表。

### 5.3.2 送审记录与订单记录

需求说明：

1. 每次送审生成独立送审记录。
2. 送审记录至少包含送审轮次、送审公证处、送审时间、送审人/触发来源、材料清单、送审结果。
3. 自动送审的触发来源记录为“生产端制作完成自动送审”。
4. 管理端再次送审的触发来源记录为“管理端手动送审”。
5. 审核驳回后再次送审，不覆盖历史驳回原因。

验收标准：

- 同一订单多次送审时可查看完整历史。
- 自动送审和手动送审来源可区分。
- 每次送审的公证处可追溯。
- 驳回原因与再次送审记录均保留。

## 5.4 agent 管理端导出委托书签名样式

### 5.4.1 委托人签名样式调整

入口：管理端 > 公证订单相关导出 > 委托书导出

需求说明：

1. 导出委托书时，委托人签名区域使用订单对应签名图片。
2. 签名需支持放大、缩小、无规则拉伸等样式变化。
3. 样式变化仅作用于签名图片显示，不改变原始签名文件。
4. 签名仍需落在委托书“委托人”签名区域内，不得遮挡正文、日期或其他字段。
5. 同一订单重复导出时，建议保持同一签名变换参数，避免同一订单多次导出差异过大。
6. 不同订单可生成不同的签名缩放和拉伸效果。

签名变换建议：

| 参数     | 建议范围           | 说明                     |
| -------- | ------------------ | ------------------------ |
| 宽度缩放 | 90% - 125%         | 控制签名横向大小         |
| 高度缩放 | 85% - 120%         | 控制签名纵向大小         |
| 横向偏移 | 签名区域内安全范围 | 避免完全居中导致样式统一 |
| 纵向偏移 | 签名区域内安全范围 | 避免压线或遮挡           |
| 拉伸策略 | 非等比缩放         | 形成轻微无规则变化       |

验收标准：

- 导出的委托书中，委托人签名有明显大小或形态变化。
- 签名不超出委托人签名区域。
- 签名不遮挡正文、日期或其他字段。
- 原始签名图片不被修改。
- 同一订单多次导出时签名样式稳定或在可接受范围内一致。

### 6.2 送审记录字段

| 字段                     | 说明                                                       |
