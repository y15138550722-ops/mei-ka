# 同步渠道显性入口 PRD

> **模块**: FE 订单管理 / 渠道同步
> **版本**: v1.0
> **最后更新**: 2026-05-14

## 1. 背景与目标

### 1.1 业务背景

订单管理列表中的“同步渠道”属于运营高频动作，当前入口收纳在“批量操作”下拉菜单内。运营人员每次执行同步都需要额外展开菜单，操作路径偏深，在高峰期容易影响处理效率。

### 1.2 问题陈述

- 高频同步入口不够显性，运营人员需要多一步点击才能触达。
- 同步操作反馈不够集中，用户需要明确知道任务是否已创建、执行中、成功或失败。
- 选中订单同步和按筛选条件同步的范围需要有清晰规则，避免误操作。

### 1.3 建设目标

| # | 目标         | 描述                                             |
| - | ------------ | ------------------------------------------------ |
| 1 | 提升触达效率 | 将“同步渠道”调整为订单管理列表工具栏独立按钮   |
| 2 | 明确同步范围 | 支持按选中订单或当前筛选条件触发同步             |
| 3 | 增强执行反馈 | 展示执行中、成功、失败状态，并可进入任务日志排查 |
| 4 | 权限可控     | 仅允许具备渠道同步权限的角色查看或使用           |

### 1.4 非目标

- 本需求不实现商户端订单抓取逻辑。
- 本需求不实现 Klook 派车信息回传。
- 本需求不重构订单核心模型，仅调整入口、交互和任务触发能力。

## 3. 用户角色与用户故事

### 3.1 用户角色

| 角色         | 说明                                     |
| ------------ | ---------------------------------------- |
| 订单运营人员 | 日常处理渠道订单、触发同步、查看同步结果 |
| 渠道运营人员 | 关注渠道订单同步质量和异常               |
| 系统管理员   | 配置权限、查看任务日志和异常记录         |

### 3.2 用户故事

#### US-1: 显性触发同步渠道

> **作为** 订单运营人员
> **我希望** 在订单管理列表中直接看到“同步渠道”按钮
> **以便于** 快速执行高频渠道同步操作，减少重复点击

**验收标准**:

- 订单管理列表工具栏展示独立的“同步渠道”按钮。
- 按钮不再仅隐藏在“批量操作”下拉菜单内。
- 用户点击后可按当前筛选条件或选中订单触发同步。
- 同步触发后展示明确的执行中、成功、失败反馈。

## 4. 功能设计

### 4.1 展示规则

| 项       | 规则                                                 |
| -------- | ---------------------------------------------------- |
| 展示位置 | 订单管理列表顶部工具栏，与“导出”“批量操作”等同级 |
| 按钮名称 | 同步渠道                                             |
| 权限控制 | 仅具备 `channel.sync.trigger` 权限的角色可见或可用 |
| 可用状态 | 至少存在可同步渠道，且用户具备对应权限时可用         |
| 禁用状态 | 无渠道权限、任务正在执行、当前筛选无可同步数据时禁用 |

### 4.2 交互规则

1. 用户在订单管理列表点击“同步渠道”。
2. 若已选中订单，系统优先对选中订单所属渠道执行同步。
3. 若未选中订单，系统按当前筛选条件和用户权限范围触发渠道同步。
4. 系统展示确认弹窗，说明本次同步范围、渠道和预计影响。
5. 用户确认后创建同步任务。
6. 系统展示任务执行状态，并在完成后提示成功或失败结果。

### 4.3 同步范围规则

| 场景                   | 同步范围                           |
| ---------------------- | ---------------------------------- |
| 有选中订单             | 仅同步选中订单对应的渠道订单       |
| 无选中订单但有筛选条件 | 按当前筛选条件范围触发同步         |
| 无选中订单且无筛选条件 | 按用户权限范围内可同步渠道触发同步 |
| 当前范围无可同步订单   | 阻断任务创建并提示用户             |

### 4.4 异常提示

| 场景         | 文案                                     |
| ------------ | ---------------------------------------- |
| 无权限       | 当前账号无渠道同步权限，请联系管理员开通 |
| 无可同步渠道 | 当前筛选范围内暂无可同步渠道订单         |
| 任务执行中   | 渠道同步任务正在执行，请稍后查看结果     |
| 同步失败     | 渠道同步失败，请查看任务日志或稍后重试   |

## 5. 任务日志

| 字段              | 类型     | 说明                                                                       |
| ----------------- | -------- | -------------------------------------------------------------------------- |
| `task_id`       | String   | 任务唯一 ID                                                                |
| `task_type`     | Enum     | 固定为 `channel_sync`                                                    |
| `channel_code`  | Enum     | 渠道编码                                                                   |
| `trigger_type`  | Enum     | `manual`                                                                 |
| `status`        | Enum     | `pending` / `running` / `success` / `partial_success` / `failed` |
| `started_at`    | DateTime | 开始时间                                                                   |
| `finished_at`   | DateTime | 结束时间                                                                   |
| `success_count` | Number   | 成功数量                                                                   |
| `failed_count`  | Number   | 失败数量                                                                   |
| `error_message` | String   | 失败原因                                                                   |
| `operator_id`   | String   | 手动触发人                                                                 |

| 编号   | 规则名称   | 规则描述                                           | 优先级 |

## 8. 验收标准

| 用例编号 | 场景            | 前置条件                 | 操作                   | 预期结果                           |
| -------- | --------------- | ------------------------ | ---------------------- | ---------------------------------- |
| TC-001   | 同步按钮展示    | 用户有渠道同步权限       | 打开订单管理列表       | 工具栏展示“同步渠道”独立按钮     |
| TC-002   | 无权限隐藏/禁用 | 用户无渠道同步权限       | 打开订单管理列表       | 不展示按钮或按钮禁用，并提示无权限 |
| TC-003   | 选中订单同步    | 已选中部分订单           | 点击“同步渠道”并确认 | 创建选中订单范围的同步任务         |
| TC-004   | 筛选条件同步    | 未选中订单但存在筛选条件 | 点击“同步渠道”并确认 | 创建当前筛选范围同步任务           |
| TC-005   | 无可同步订单    | 当前范围无可同步渠道订单 | 点击“同步渠道”       | 阻断任务创建并提示无可同步渠道     |
| TC-006   | 任务执行反馈    | 同步任务执行中           | 查看页面提示           | 展示执行中、成功或失败结果         |

## 9. 风险与待确认

| 风险/待确认项 | 说明                                           | 建议处理                           |
| ------------- | ---------------------------------------------- | ---------------------------------- |
| 同步范围误解  | 选中订单和筛选条件并存时用户可能不清楚生效范围 | 确认弹窗明确展示“按选中订单同步” |
| 权限粒度      | 是否按渠道配置触发权限需业务确认               | 权限模型预留渠道维度               |
| 任务并发      | 高频点击可能造成重复同步                       | 增加任务执行中禁用和防重复提交     |
