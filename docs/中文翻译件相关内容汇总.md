# 中文翻译件相关内容汇总

本文把项目里和“中文翻译件”直接相关的代码、配置、文档和素材做一次汇总，方便快速定位。

## 1. 项目定位

项目简介里已经把业务范围写得很清楚：平台面向 IDP 业务，也覆盖多国官方翻译件办理。[README.md](../README.md:3)

## 2. 入口与路由

- 应用入口在 `src/App.tsx`，其中单独懒加载了中文翻译件页面。[src/App.tsx](../src/App.tsx:21)
- 访问 `/license-officer` 会自动跳转到 `/license-officer/orders/chinese-translation`。[src/App.tsx](../src/App.tsx:97)
- 中文翻译件页面的路由也单独注册了出来。[src/App.tsx](../src/App.tsx:100)

## 3. 驾照官后台菜单

- 后台菜单里有“中文翻译件”入口，并且会根据当前路径高亮。[src/modules/license-officer/LicenseOfficerLayout.tsx](../src/modules/license-officer/LicenseOfficerLayout.tsx:17)
- 左侧菜单结构里，中文翻译件挂在“订单管理”下。[src/modules/license-officer/LicenseOfficerLayout.tsx](../src/modules/license-officer/LicenseOfficerLayout.tsx:38)

## 4. 中文翻译件页面

核心页面是 `src/modules/license-officer/ChineseTranslationOrders.tsx`。[文件](../src/modules/license-officer/ChineseTranslationOrders.tsx:86)

这个页面主要做了几件事：

1. 从本地订单数据里筛出中文翻译件相关订单。
2. 把订单状态映射成生产视角的状态：未翻译、未制作、未发货、已发货、已取消。
3. 支持按状态、订单号、关键词、办理类型、国家筛选。
4. 展示订单号、订单类型、状态、发起时间、订单信息、收货信息、物流信息和操作按钮。
5. 配合分页组件分页展示。[src/modules/license-officer/ChineseTranslationOrders.tsx](../src/modules/license-officer/ChineseTranslationOrders.tsx:113)

页面里还包含这些提取逻辑：

- `isChineseTranslationOrder`：判断是否属于中文翻译件订单。[src/modules/license-officer/ChineseTranslationOrders.tsx](../src/modules/license-officer/ChineseTranslationOrders.tsx:76)
- `getOrderInfo`：整理订单信息展示字段。[src/modules/license-officer/ChineseTranslationOrders.tsx](../src/modules/license-officer/ChineseTranslationOrders.tsx:55)
- `getReceiptInfo`：整理收货信息。[src/modules/license-officer/ChineseTranslationOrders.tsx](../src/modules/license-officer/ChineseTranslationOrders.tsx:64)
- `getShippingInfo`：整理物流信息。[src/modules/license-officer/ChineseTranslationOrders.tsx](../src/modules/license-officer/ChineseTranslationOrders.tsx:70)

表格列包含序号、订单号、订单类型、订单状态、发起时间、订单信息、收货信息、物流信息和操作。[src/modules/license-officer/ChineseTranslationOrders.tsx](../src/modules/license-officer/ChineseTranslationOrders.tsx:270)

## 5. 订单导出

中文翻译件的导出逻辑在 `src/shared/utils/exportTranslationOrders.ts`。[文件](../src/shared/utils/exportTranslationOrders.ts:154)

它做了这些事情：

- 定义导出行结构 `TranslationOrderExportRow`。[src/shared/utils/exportTranslationOrders.ts](../src/shared/utils/exportTranslationOrders.ts:3)
- 从 Excel 模板文件加载表格。[src/shared/utils/exportTranslationOrders.ts](../src/shared/utils/exportTranslationOrders.ts:17)
- 把订单行写入工作表，并保留模板样式。[src/shared/utils/exportTranslationOrders.ts](../src/shared/utils/exportTranslationOrders.ts:33)
- 生成带北京时间戳的导出文件名。[src/shared/utils/exportTranslationOrders.ts](../src/shared/utils/exportTranslationOrders.ts:47)

## 6. 订单列表中的翻译订单

普通订单管理里的翻译订单列表也和这条业务线有关。

- `TranslationOrderList.tsx` 会先筛出 `productCategory === 'translation'` 的订单。[src/modules/order-management/TranslationOrderList.tsx](../src/modules/order-management/TranslationOrderList.tsx:31)
- 页面支持按翻译订单状态统计、筛选和导出。[src/modules/order-management/TranslationOrderList.tsx](../src/modules/order-management/TranslationOrderList.tsx:131)
- 导出时会调用 `exportTranslationOrders`。[src/modules/order-management/TranslationOrderList.tsx](../src/modules/order-management/TranslationOrderList.tsx:159)

## 7. 产品与翻译分类

翻译类产品在 mock 数据里单独配置了类别和具体商品名，例如：

- 驾照翻译国际认证件（小白本）
- NAATI 澳大利亚认证
- NZTA 新西兰认证
- 西班牙语言宣誓翻译
- 德语宣誓翻译
- 法语宣誓翻译

这些内容都归在 `translation` 类别下。[src/services/mockDataService.ts](../src/services/mockDataService.ts:58)

国际化配置里也把 `product.category.translation` 单独映射成中文和英文文案。[src/shared/i18n/config.ts](../src/shared/i18n/config.ts:140)
