AGENTS.md
此文件是本项目中AI智能体工作流的全仓库唯一事实来源。
H2
必读首读
• 对于specs/**、文档/**、README.md、CHANGELOG.md下的任何规范/文档变更：
◦ 读取.agent/rules/role-pm-architect.md
◦ 阅读文档/templates/prd_spec_template.md
• 对于任何代码更改：
◦ 读取.agent/rules/coder-agent.md
◦ 读取.agent/rules/module-boundaries.md
◦ 如果任务涉及列表/表单页面，还需阅读.agent/rules/Design Baselines.md
H2
规则优先级
• 系统 / 开发者说明 > AGENTS.md >.agent/rules/*.md > 任务提示
• 如果规则与当前任务冲突，应停止并明确声明偏差，而不是默默忽略规则
• 如果一个任务同时涉及规范和代码，先加载规范规则，再加载编码规则
H2
任务路由
• 规格 / PRD / 文档工作 -> PM架构师规则
• 编码工作 -> 编码人员 + 模块边界规则
• 审查工作 -> 以结果为导向，采用魔鬼代言人模式
• 临时/实验性页面工作 -> 需要明确的任务范围；不要悄无声息地改造现有页面
• 重写现有文档 -> 保留业务事实，但将结构规范为当前活动的模板/规则集
H2
不可协商事项
• 在加载匹配规则文件之前请勿开始编写规范
• 编辑规格文档时，请遵循PRD模板结构
• 当任务要求创建临时/新页面时，除非明确允许，否则不要改造现有页面
• 如果未加载匹配的规则文件，则不要开始编写规范或代码
•对于特定任务，在撰写文档之前列出缺失的模板部分/缺失的字段定义
H2
规格清单
• 背景 / 上下文
• 用户故事
• 验收标准
• 逻辑流程 / 交互逻辑
• 至少3个边缘情况 / 异常场景
• 跟踪事件
• 国际化考量和资源键建议
• 复杂页面的逻辑视图
• 过滤器/列表/表单的字段级定义
H2
代码检查清单
• 尊重模块边界，不要悄无声息地跨越模块
• 将新页面/组件放置在正确的模块路径中
• 仅在与目标范围明确兼容时复用共享组件
• 不要用便捷的改造来绕过规范意图
• 保持命名、所有权和公共接口的明确性
H2
响应协议
• 在首次更新中，说明加载了哪些规则文件
• 在最终更新中，说明与规则的任何偏差
